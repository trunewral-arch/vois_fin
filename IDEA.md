# 🎙️ Voice Expense — Умный голосовой учёт расходов в стиле Apple

Минималистичное веб-приложение (PWA) для ультра-быстрого внесения личных расходов с помощью голоса. Принцип работы: **«одно касание — наговорил — готово»**, без клавиатуры, без долгих переходов по меню и без лишних форм.

---

## 1. Концепция и ключевая идея

Большинство финансовых приложений требуют слишком много действий: открыть приложение, нажать «плюс», выбрать категорию из длинного списка, ввести сумму с клавиатуры, написать комментарий и сохранить. В результате траты перестают вноситься уже через неделю.

**Voice Expense** решает эту проблему:
1. Вы открываете приложение (ярлык на экране смартфона открывается мгновенно, как нативное приложение).
2. На экране сразу видны **8 главных кнопок-категорий**.
3. Зажимаете нужную кнопку пальцем (Push-to-Talk) и произносите фразу в свободном формате, например:
   - *«430 хлеб»*
   - *«капучино и круассан 320»*
   - *«такси до дома 650»*
   - *«двести аптека»*
4. Отпускаете кнопку — умный алгоритм мгновенно извлекает сумму и описание.
5. Всплывает аккуратная плашка предпросмотра на 3 секунды с возможностью отменить или скорректировать запись, после чего трата фиксируется в локальной базе данных.
6. Экран ниже сразу обновляет статистику по категории и добавляет запись в ленту истории.

## 2. Дизайн и эстетика (Apple Style)

Интерфейс спроектирован по канонам **Apple Human Interface Guidelines (iOS)**:
- **Типографика**: системный шрифт Apple (SF Pro Display / SF Pro Text), крупные чёткие цифры, выверенная иерархия заголовков.
- **Цветовая палитра**:
  - Светлая и тёмная темы (подстраиваются под тему iOS/Android).
  - Фоновый цвет: глубокий нейтральный (`#F2F2F7` для светлой, `#000000` / `#1C1C1E` для тёмной).
  - Мягкие, приглушённые системные цвета Apple (System Blue, System Green, System Orange, System Indigo, System Pink и др.) для акцентов категорий.
- **Карточки и кнопки**:
  - Скругление squircle (`border-radius: 20px–24px`).
  - Эффект матового стекла (*Frosted Glass / Backdrop Blur*).
  - Тактильный виброотклик (*Haptic Feedback* через Web Vibration API) при начале и завершении записи.
  - Плавная микроанимация масштабирования карточки при удержании (*spring-анимация*) и лёгкая пульсация контура микрофона.

### Детализация зон экрана:
1. **Шапка (Header & Баланс)**:
   - Крупная сумма расходов за выбранный период (Сегодня / Неделя / Месяц).
   - Кнопка настроек категорий `[⚙️]` и кнопка резервного копирования / экспорта `[↑]`.
2. **Сетка категорий (8 карточек)**:
   - 8 крупных интерактивных карточек (сетка 2 колонки × 4 строки), оптимизированных для нажатия большим пальцем одной руки.
   - На карточке: иконка, название категории и текущая сумма расходов за выбранный период.
   - Механика **Push-to-Talk**: нажал и держишь — идёт запись, отпустил — мгновенный разбор.
3. **Плавающий баннер подтверждения (Dynamic Island style)**:
   - При завершении записи сверху плавно выплывает компактный виджет:
     > *«🛒 Продукты: 430 ₽ — хлеб»*
     > *[Отменить] • автосохранение через 3 сек.*
4. **Статистика по категориям**:
   - Элегантный Apple-style горизонтальный stacked bar (как график батареи или памяти в iOS), показывающий долю каждой из 8 категорий в общих расходах.
5. **История расходов**:
   - Хронологический список последних операций.
   - Поля каждой записи:
     1. Категория (иконка + название).
     2. Сумма (крупный полужирный шрифт с валютой `₽`).
     3. Текстовое описание.
     4. Время операции.
   - Возможность тапнуть по любой строке для быстрого редактирования (сумма / текст / смена категории) или смахнуть влево (Swipe-to-delete) для удаления.

## 4. Категории по умолчанию (8 слотов)

Все 8 кнопок можно в любой момент переименовать, сменить иконку и акцентный цвет:

1. **🛒 Продукты** (Supermarket / Groceries) — зеленый/мятный акцент
2. **☕ Кафе и перекусы** (Coffee & Dining) — оранжевый акцент
3. **🚕 Транспорт и такси** (Transport) — синий акцент
4. **🏠 Дом и быт** (Home & Bills) — индиго акцент
5. **🛍️ Покупки и одежда** (Shopping) — фиолетовый акцент
6. **💊 Здоровье и аптека** (Health & Care) — красный/коралловый акцент
7. **🍿 Развлечения и отдых** (Entertainment) — желтый акцент
8. **📦 Разное** (Other) — нейтральный графитовый акцент

## 5. Голосовое распознавание и алгоритм парсинга

- **Движок**: Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`), встроенный прямо в движки браузеров (Safari на iOS, Chrome на Android).
  - Не требует сторонних платных API, токенов и подписок.
  - Работает локально и быстро.
- **Интеллектуальный разбор фразы (Parser Engine)**:
  - Алгоритм поддерживает **любой порядок слов**:
    - `[Сумма] [Описание]` -> *«430 хлеб»*
    - `[Описание] [Сумма]` -> *«хлеб четыреста тридцать»*
    - Сложные фразы с предлогами: *«такси до вокзала за пятьсот рублей»* -> сумма: `500`, описание: `такси до вокзала`.
  - Встроенный словарь русских числительных (распознавание слов *«сто»*, *«двести пятьдесят»*, *«полторы тысячи»* и перевод их в числовой формат).

## 6. Хранение данных, приватность и PWA

- **Полная автономность и приватность**: Все данные хранятся исключительно на устройстве пользователя в базе данных **IndexedDB** браузера. Никакие финансовые данные не уходят на удалённые серверы.
- **PWA (Progressive Web App)**:
  - Приложение устанавливается в один клик: Safari -> «Поделиться» -> «На экран "Домой"».
  - Полноэкранный режим (без адресной строки браузера и рамок), иконка на рабочем столе телефона.
  - Работает офлайн даже без подключения к интернету.
- **Экспорт данных**:
  - Кнопка выгрузки истории трат в формате **CSV / Excel** за выбранный месяц или за всё время.
  - Возможность создать резервную копию базы данных (JSON) и восстановить её.

## 7. Технический стек для реализации

- **Ядро**: Чистый, быстрый и легковесный современный фронтенд (React / Vite или быстрый Vanilla TypeScript/JS).
- **Стилизация**: Tailwind CSS (утилиты для iOS-подобного blur, squircle-скруглений, системных отступов safe-area под вырез экрана iPhone).
- **Хранилище**: IndexedDB с оберткой Dexie.js (мгновенные выборки, фильтрация по датам и категориям).
- **Иконки**: Lucide Icons (минималистичный стиль, гармонирующий с символами Apple SF Symbols).
- **PWA**: Web App Manifest, Service Worker для мгновенной загрузки офлайн.

## 8. Дорожная карта реализации (следующие шаги)

1. **Шаг 1**: Каркас проекта (Vite + Tailwind + PWA Manifest + Lucide Icons).
2. **Шаг 2**: Модуль базы данных (IndexedDB): инициализация 8 категорий по умолчанию, сохранение, удаление, редактирование транзакций.
3. **Шаг 3**: Модуль распознавания речи и парсинга (Web Speech API + распознавание чисел и названий).
4. **Шаг 4**: Apple-интерфейс:
   - Крупная шапка с балансом.
   - 8 кнопок категорий с Push-to-Talk и тактильной анимацией.
   - Плавающий баннер подтверждения (3-секундный таймер отмены).
   - Индикатор статистики (сегментированный бар).
   - Список последних операций со свайпами и редактированием.
5. **Шаг 5**: Экспорт в CSV/Excel и экран настроек категорий.
6. **Шаг 6**: Полировка под мобильные устройства (safe-area для iPhone с «островом» / "чёлкой", виброотклик, PWA-иконки).
