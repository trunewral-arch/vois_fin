🎙️ Доступ к микрофону

Почему микрофон заблокирован?
Мобильные браузеры (Chrome, Яндекс и др.) по правилам безопасности блокируют доступ к микрофону при открытии файла из Проводника (схема content:// или file://). Для работы микрофона браузеру обязательно требуется протокол HTTPS.
Как включить голосовой ввод на телефоне:
  1. Загрузите файл index.html на любой бесплатный статический хостинг с HTTPS (например, GitHub Pages, Netlify Drop или Cloudflare Pages).
  2. Откройте полученную https://... ссылку на телефоне.
  3. При первом зажатии кнопки браузер спросит «Разрешить доступ к микрофону?» — нажмите «Разрешить».
  4. Нажмите в меню браузера «Добавить на главный экран» — приложение развернётся на весь экран без адресной строки как нативное PWA.
💡 Прямо сейчас без HTTPS:
Используйте быстрый короткий тап по любой категории для моментального ручного ввода суммы или кнопку ✨ в шапке для теста распознавания готовыми фразами.
