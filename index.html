🎙️ Доступ к микрофону

Почему микрофон заблокирован?
Мобильные браузеры (Chrome, Яндекс) блокируют микрофон при открытии файла из Проводника (схема content:// или file://). Для работы микрофона требуется HTTPS.
Как включить голосовой ввод:
  1. Включите GitHub Pages в репозитории проекта (Settings → Pages → branch: main → Save).
  2. Откройте полученную ссылку https://... на смартфоне.
  3. Нажмите «Разрешить» при запросе доступа к микрофону.
💡 Прямо сейчас: используйте короткий тап по карточке для ручного ввода суммы или кнопку ✨ для проверки парсера.
